# P3-3 — The same semantic value is accepted differently by the two front ends: …

## Finding / 问题

- EN: The same semantic value is accepted differently by the two front ends: XML follows HTML boolean semantics, so `required="1"`, `"yes"`, `"on"`, `""` and `"required"` are all true, while YAML requires a native scalar and rejects `required: 1` (integer) and `rows: '4'` (quoted). Same contract, same value, one side legal, one side an error.
- 中文: 同一语义值在两个前端的接受面不同：XML 走 HTML 布尔语义，required="1"、"yes"、"on"、""、"required" 全为真；YAML 要求原生标量，required: 1（整数）与 rows: '4'（引号）都报错。同契约同值，一端合法一端报错。
- Where / 位置: `src/Compiler.php:561-578 vs migears-yaml-pages/src/Compiler.php:53-63`
- Verification / 验证: reproduced / 已实证
